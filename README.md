# Code Review Agent - 智能代码审查助手
## 项目简介
Code Review Agent 是一个基于大语言模型（通义千问）的智能代码审查助手。
它能够自动分析代码质量、发现潜在Bug和安全问题，并给出具体的改进建议。
## 功能特性
- **Bug检测**：自动发现潜在的运行时错误和逻辑错误
- **安全审查**：识别安全漏洞和不安全的编码实践
- **规范检查**：检查命名规范、代码格式和注释完整性
- **改进建议**：给出具体的重构建议和优化后的代码
- **工具集成**：支持文件读取、代码执行、代码统计等工具
- **上下文对话**：支持针对审查结果进行多轮追问
## 技术架构
用户输入 --> Agent主循环 --> 工具调用（文件读取/代码执行/代码统计）
|
LLM推理（通义千问）
|
输出审查报告

TEXT
## 技术栈
- **编程语言**：Python 3.9+
- **LLM服务**：通义千问（qwen-plus）
- **Agent框架**：自研Agent循环
- **工具集成**：文件读取、代码执行、代码统计、语言检测
- **界面**：命令行交互
## 快速开始
### 1. 安装依赖
```bash
pip install dashscope
```

### 2. 配置API Key

编辑 config.py，填入你的通义千问API Key：


```
DASHSCOPE_API_KEY = "xxxxx"
```

### 3.运行程序

```
python main.py
```



## 使用方法

| 命令               | 说明             |
| ------------------ | ---------------- |
| /review <文件路径> | 审查代码文件     |
| /paste             | 粘贴代码进行审查 |
| /chat <问题>       | 针对审查结果追问 |
| /reset             | 重置对话历史     |
| /help              | 显示帮助         |
| /quit              | 退出程序         |

### 使用示例

```
请输入命令 > /review examples/sample.py
```


程序会自动分析代码并输出包含以下内容的审查报告：

1.总体评价（1-5星评分）

2.潜在Bug列表

3.安全问题列表

4.代码规范问题

5.改进建议

6.修复后的完整代码
